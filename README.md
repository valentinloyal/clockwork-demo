# Clockwork, démo

Démo publique de **Clockwork**, mon planning étudiant qui se replanifie automatiquement à partir de l'intranet de l'école et de notes écrites en langage naturel.

**Tester la démo : https://valentinloyal.github.io/clockwork-demo/**

- Toutes les données sont fictives.
- La démo tourne entièrement dans le navigateur : aucun appel à une base de données, à Notion ou à une IA.
- Ce dépôt ne contient que le site compilé. Le code source de la version complète (React, Vite, Vercel, Neon, Notion, Claude) reste privé.
